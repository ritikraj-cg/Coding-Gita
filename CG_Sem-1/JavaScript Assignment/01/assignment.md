### Q1. What is JavaScript?
JavaScript is a high-level, dynamically typed programming language used to make web pages interactive and dynamic.

### Q2. Who created JavaScript and in which year?
JavaScript was created by Brendan Eich in 1995.

### Q3. What was the original name of JavaScript?
Its original name was Mocha. It was later called LiveScript and then JavaScript.

### Q4. Is JavaScript the same as Java? Give one major difference.
No. JavaScript and Java are different programming languages. Java is class-based, while JavaScript is mainly used for web interactivity and can also run outside browsers.

### Q5. What does high-level mean?
JavaScript uses human-readable syntax and hides many low-level computer details.

### Q6. Is JavaScript compiled or interpreted?
JavaScript is commonly described as an interpreted language because the JavaScript engine executes the code. Modern engines also use JIT compilation for performance.

### Q7. JavaScript engines
Google Chrome: V8
Mozilla Firefox: SpiderMonkey
Apple Safari: JavaScriptCore

### Q8. What is Dynamic Typing?
Dynamic typing means a variable can contain values of different data types at different times.

### Q9. Static vs Dynamic website
A static website mainly displays fixed content. A dynamic website can change its content or behavior based on users, data, or actions.

### Q10. Three pillars of Front-end Web Development
1. HTML - Structure and content.
2. CSS - Design and appearance.
3. JavaScript - Behavior and interactivity.

### Q11. Frontend vs Backend
Frontend is what users see and interact with. Backend handles server-side logic, databases, and APIs.

### Q12. What is Node.js?
Node.js is a JavaScript runtime that allows JavaScript to run outside the browser.

### Q13. What is ECMAScript?
ECMAScript is the standardized specification that defines the core rules and features of JavaScript. JavaScript is an implementation of the ECMAScript standard.

## Section D: Conceptual Questions

### Q14. Static and dynamic website
A static website generally shows fixed content, such as a simple HTML portfolio. A dynamic website can generate or change content according to users or data, such as an online shopping website.

### Q15. Two JavaScript features
1. Event-driven programming allows JavaScript to respond to clicks, typing, and other events.
2. JavaScript can change HTML content, styles, and elements while the page is running.

### Q16. Four areas where JavaScript is used
1. Backend/server applications - Node.js
2. Mobile applications - React Native
3. Desktop applications - Electron
4. Cross-platform applications - Ionic

### Q17. Internal vs external JavaScript
JavaScript can be written inside an HTML <script> tag or in a separate .js file connected using <script src="...">.

Two advantages of external JavaScript:
1. The same code can be reused on multiple pages.
2. HTML remains cleaner and JavaScript is separated from page structure.

### Q18. Frontend and Backend restaurant analogy
Frontend is like the restaurant's customer area and menu, where the customer sees and interacts. Backend is like the kitchen, where the requested work is processed. An API can be compared to the waiter carrying requests between them.

### Q19. Why learn JavaScript?
1. It is a major frontend technology.
2. It creates interactive web pages.
3. It can run outside browsers with Node.js.
4. It is useful for learning frameworks and libraries such as React.
5. It can be used for many types of applications.
